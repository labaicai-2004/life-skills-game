# 自然女声录音替换实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将游戏内 36 条固定录音替换为用户确认的上一版自然女声音色，并使用更自然的老师讲话停顿。

**Architecture:** 使用已确认的合成女声样本作为统一声音参考，离线制作并检查全部 WAV 后再替换项目录音。网页继续播放本地固定文件，不连接生成服务、不调用设备语音，音乐和 21 步行为保持原样。

**Tech Stack:** 现有原生 HTML/JavaScript、PCM WAV、离线录音制作工具与 Node 自动检查。

**Spec:** `docs/design-spec.md` 音效规范及用户本轮确认：保留自然女声，指令后留反应时间，两句鼓励连贯，不使用成熟老师版音色。

## Global Constraints

- 所有应用代码在 `index.html` 中，不拆分为多个文件。
- 不引入外部运行依赖；服务仅用于离线制作素材。
- 不修改三关 21 步、儿童研究数据、隐藏入口或木琴音乐。
- 36 条文字及映射完整保留，语音在不同设备上保持一致。
- 本轮批准的自然录音优先于旧的“婷婷女声 0.75x”制作规定；播放时不再次机械减速或改变音高。

## Review Focus

- 制作中断或公开服务额度不足：候选文件可续作，不让游戏混用半套录音。
- 中文漏字、多字或异常停顿：每条录音需要听感检查，不以文件生成成功代替检查。
- 声音不一致：各条均参考同一已确认样本，不重新随机设计音色。
- 浏览器缓存旧音频：更新资源版本，确保线上刷新后加载新录音。
- 录音播放结束或出错：原有音乐压低、恢复、重播及退出处理仍然有效。

**Interfaces:** 消费现有 `VOICE_MAP` 的 36 个文本；产出相同文本的一套 16 bit 单声道 PCM WAV 与来源、时长清单。
