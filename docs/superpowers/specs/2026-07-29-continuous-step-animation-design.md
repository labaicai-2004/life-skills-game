# 21步连续示范动画设计

## 目标

为刷牙、洗脸、穿衣三项技能的全部21个步骤增加连贯动画。每一步同时具备“正确动作示范”和“前序结果保留”，帮助儿童理解完整任务链，但不代替儿童作答，也不改变现有成功判定、研究数据、语音、按钮或页面布局。

## 核心交互规则

1. 新步骤画面稳定显示后等待2000毫秒，再开始循环示范正确动作。
2. 儿童在交互区域首次触摸或按下鼠标时，当前示范立即暂停并保持静止，避免动画与真实拖拽竞争。
3. 示范元素统一使用 `pointer-events:none`，不得遮挡点击、滑动或拖拽目标。
4. 儿童完成当前步骤后，将该步骤产生的结果写入当前技能的场景状态；进入下一步时根据状态渲染已完成结果。
5. 返回首页、重新开始关卡或切换技能时，清空场景状态和全部动画计时器。
6. 示范动画不调用 `handleStepSuccess()`，不会自动完成步骤，也不写入行为完成记录。
7. 错误后不自动恢复示范，儿童可依据画面上的箭头和语音继续尝试。
8. 普通儿童训练默认启用动画；研究模式必须根据实验条件控制动画，避免视觉示范污染独立完成数据。

## 技术方案

继续使用现有单文件 HTML、CSS、JavaScript 架构，在 `index.html` 内增加三个边界清晰的单元：

### AnimationController

负责每一步示范动画的生命周期：

- `schedule(stage, levelId, stepId)`：步骤加载完成后设置2000毫秒启动计时器。
- `start(stage)`：给当前 `.step-stage` 添加示范运行状态。
- `pause(stage)`：儿童首次交互时暂停当前示范。
- `clear()`：切换步骤、返回首页或重新开始时清理计时器和运行状态。

控制器只管理动画，不判定儿童响应，不调用成功或错误处理函数。

### AnimationPolicy

负责决定当前Session是否允许播放连续示范，规则固定如下：

| 使用情境 | 默认动画状态 | 理由 |
|---|---|---|
| 普通儿童训练 | 开启 | 提供完整教学支持 |
| Intervention / Teaching | 开启 | 动画作为干预期视觉教学支持 |
| Baseline / Assessment | 关闭 | 避免提示影响独立表现测量 |
| Maintenance | 关闭 | 默认观察技能保持，不主动提供示范 |

研究模式中的关闭状态优先级最高。动画关闭时，场景仍显示静态对象和当前系统允许的其他提示；本设计不改变实验阶段与现有训练模式的映射关系。后续如允许研究者在维持期手动开启动画，必须将该设置和实际播放情况写入Session元数据，本阶段不提供该开关。

### SkillSceneState

保存当前关卡内已完成的视觉结果：

```javascript
{
  brush: {
    toothbrushFound: false,
    toothpasteApplied: false,
    toothbrushPickedUp: false,
    leftBrushed: false,
    rightBrushed: false,
    rinsed: false,
    mouthWiped: false
  },
  wash: {
    faucetOn: false,
    waterCollected: false,
    towelWet: false,
    towelWrung: false,
    faceWashed: false,
    towelRinsed: false,
    faucetOff: false
  },
  dress: {
    jacketFound: false,
    frontIdentified: false,
    leftSleeveOn: false,
    rightSleeveOn: false,
    jacketPulledDown: false,
    zipperClosed: false,
    collarAdjusted: false
  }
}
```

`handleStepSuccess()`只在儿童真实完成或现有提示系统完成步骤时更新对应状态；动画本身不更新状态。

### 场景动画标记

`buildScene()`继续负责现有对象布局，仅为需要动画的对象增加稳定类名和状态装饰层，例如 `.demo-toothpaste`、`.demo-water-stream`、`.state-toothpaste-on-brush`。所有新增装饰层都位于现有交互对象之下或设置为不可触控。

## 21步动画映射

### 刷牙

| 步骤 | 示范动画 | 下一步保留状态 |
|---|---|---|
| 1 找到牙刷 | 牙刷轻微上浮并发出柔和光晕 | 牙刷被选中标记 |
| 2 挤牙膏 | 牙膏软管轻压，少量牙膏沿垂直方向移动到刷毛 | 刷毛上保留牙膏 |
| 3 拿起牙刷 | 牙刷轻轻抬起并倾斜 | 后续刷牙场景显示已拿起牙刷 |
| 4 刷左边牙齿 | 示范牙刷在左侧嘴部上下往返 | 左侧出现短暂洁净闪光 |
| 5 刷右边牙齿 | 示范牙刷在右侧嘴部上下往返 | 左右两侧均显示完成效果 |
| 6 漱口 | 水杯靠近嘴部并轻微倾斜 | 嘴部保持清洁状态 |
| 7 擦嘴巴 | 毛巾在嘴部左右往返 | 最终画面显示干净嘴部 |

### 洗脸

| 步骤 | 示范动画 | 下一步保留状态 |
|---|---|---|
| 1 打开水龙头 | 小手向上推动，水流渐显 | 水流持续显示 |
| 2 接水 | 小手移到水流下方，水滴聚集 | 双手带少量水滴 |
| 3 打湿毛巾 | 小手与毛巾上下轻搓，毛巾颜色加深 | 毛巾保持湿润 |
| 4 拧干毛巾 | 毛巾两端反向轻扭，水滴减少 | 毛巾保持湿润但不滴水 |
| 5 擦脸 | 毛巾在脸部上下移动 | 脸部增加清洁闪光 |
| 6 冲洗毛巾 | 毛巾靠近水流，污渍效果淡出 | 毛巾恢复干净湿润状态 |
| 7 关水龙头 | 小手向下推动，水流渐隐 | 最终画面无水流 |

### 穿衣

| 步骤 | 示范动画 | 下一步保留状态 |
|---|---|---|
| 1 找到衣服 | 外套轻微上浮并发出柔和光晕 | 外套保持展开 |
| 2 分清正反面 | 外套轻微左右翻转后停在正面 | 正面朝外 |
| 3 伸左手进袖子 | 小手移向左袖口并部分进入 | 左袖呈穿好状态 |
| 4 伸右手进袖子 | 小手移向右袖口并部分进入 | 双袖呈穿好状态 |
| 5 拉好衣服 | 小手和衣身共同向下移动 | 衣身保持平整 |
| 6 拉上拉链 | 拉链头沿中线向上移动 | 拉链保持闭合 |
| 7 整理衣领 | 小手在领口左右轻移，衣领恢复对称 | 最终画面衣着整齐 |

## 与现有系统的关系

- `loadStep()`：切换前清理旧动画；新场景进入完成后安排示范。
- `attachGestureListeners()`：首次 `touchstart` 或 `mousedown` 时暂停示范。
- `handleStepSuccess()`：在现有成功反馈之前记录当前步骤的视觉状态。
- `goHome()`、`startLevel()`：清空动画控制器和技能状态。
- `ResearchCollector`、`BehaviorTracker`、`UnifiedDataManager`：不修改数据字段和写入规则。
- `PROMPT_LEVELS`：本轮不调整提示等级理论；连续动画是否播放由 `AnimationPolicy` 独立控制。
- `ResearchMode`：仅读取现有 `active`、`phase` 和训练模式状态来决定动画开关，不改变阶段选择、提示等级或数据写入流程。

## 性能与无障碍

- 只使用 `transform`、`opacity` 和少量滤镜动画，避免频繁改变布局。
- 同一时刻只允许运行当前步骤的一个示范时间线。
- 动画周期控制在1.2至2.4秒，幅度保持克制。
- 支持 `prefers-reduced-motion: reduce`：关闭循环移动，仅保留静态状态提示。
- 所有新增动画在 iPad Safari 中不得引起页面滚动、闪烁或触控延迟。

## 异常与恢复

- 如果目标元素不存在，控制器跳过该步骤动画，游戏交互仍可继续。
- 快速切换步骤时，旧计时器必须被清除，不能在新场景中启动。
- 页面离开或进入后台时，浏览器原生暂停动画；返回后仅当前步骤可以恢复。
- 动画资源全部由现有图片和 CSS 构成，不增加网络依赖。

## 验证标准

1. 三项技能共21个步骤均能显示对应示范动画。
2. 每步进入后约2000毫秒开始动画，首次触摸后立即暂停。
3. 示范期间儿童仍可点击或拖拽，成功阈值与原版本一致。
4. 每项技能的前序结果只在该技能内保留，返回首页后清空。
5. 示范动画不会自动完成步骤，不会额外产生 `step_success` 或 `researchRecords` 记录。
6. 普通训练和 Intervention / Teaching 中动画正常播放。
7. Baseline / Assessment 和 Maintenance 中不启动示范计时器，且不残留动画类名。
8. JavaScript语法检查通过，控制台无新增错误。
9. 桌面端完整走通21步，并在iPad Safari进行触控和性能复核。

## 本阶段不包含

- 不修改牙刷、牙膏及其他图片素材。
- 不改变 Least-to-Most Prompting 的等级定义。
- 不改变 Baseline、Intervention、Maintenance 与训练模式的既有关系，只读取当前条件控制动画开关。
- 不新增“观看示范”按钮。
- 不引入视频、GIF、Canvas、第三方框架或外部依赖。
