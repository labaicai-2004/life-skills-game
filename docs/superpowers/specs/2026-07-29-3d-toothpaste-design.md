# 立体牙膏素材设计

## 目标

将现有带品牌文字的牙膏图片替换为适合儿童生活技能训练的无品牌立体模型，同时不改变页面布局、交互判定与21个步骤流程。

## 视觉方案

- 柔和卡通3D产品模型，形状保持为易识别的牙膏软管。
- 主体为白色软管，搭配蓝色旋盖和简洁红蓝图案。
- 不包含品牌、文字、水印或额外物品。
- 使用透明背景，四周保留安全留白，确保旋转和缩放后不被裁切。
- 保持清晰轮廓和适度高光，兼顾立体感与低认知负担。

## 集成约束

- 继续使用 `toothpaste.png`，不改现有页面结构。
- 只更新图片缓存版本号。
- 不改图片显示尺寸、位置、手势监听和判定逻辑。

## 验证

- 检查 PNG 具有透明通道和透明边角。
- 检查牙膏主体完整、无文字、无品牌。
- 本地启动网页，验证刷牙第2步正常显示。
- 静态核对全部21个步骤定义和交互代码未被修改。
