## 日常维护规范

1. 修改前阅读本文件和相关设计规范，并在 `dev-logs/` 记录当天计划。
2. 应用代码只修改 `index.html`，不引入框架、CDN 或第三方依赖；图片放在项目目录内。
3. 每次修改后先运行相关自动检查，再在桌面浏览器检查受影响步骤；涉及行为或视觉规范时同步更新文档。
4. 仅在素材确认没有运行页面、测试和当前规范引用时，使用显式文件名删除；不删除外部参考图或历史资料。
5. 修改稳定且获得用户确认后，提交并推送更新。
